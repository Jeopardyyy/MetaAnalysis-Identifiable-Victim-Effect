# MetaAnalysis-Identifiable-Victim-Effect
Re-analysis of the Identifiable Victim Effect (IVE)

Reproducible R analysis of the meta-analysis by Lee & Feeley (2016), examining the identifiable victim effect and the robustness of the reported estimate to alternative random-effects estimation and publication-bias diagnostics.

This project was originally completed as part of a Research Assistant selection exercise at Warwick Business School.
